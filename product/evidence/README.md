# Synthetic evidence index

> **Provenance label: SYNTHETIC / DEMO-ONLY.** Every record in this directory was authored for the HoloMart demo. It is not derived from real interviews, tickets, telemetry, vendors, sellers, prices, or shoppers and must not be presented as factual market research.

The evidence intentionally disagrees in places. It supports discussion, not automatic prioritization.

| Evidence | IDs | Provenance and limitation |
| --- | --- | --- |
| [Shopper and support signals](shopper-research-signals.md) | `CI-*`, `SS-*` | Fictional composite notes and tickets; tiny, non-representative sample |
| [Usage and analytics](usage-analytics.json) | `AN-*` | Hand-authored aggregate event counts for an invented 14-day preview cohort |
| [Market and competitive notes](market-notes.md) | `MK-*` | Generic fictional marketplace patterns; no live vendor, price, or feature claims |

## Reading guidance

- A quote is a prompt for a question, not proof.
- Counts are directional examples and do not establish causality.
- Competitive patterns describe possible expectations, not parity requirements.
- Synthetic prices are interface content, not valuations.
- Roadmap initiatives cite IDs and counts so a human can inspect support and counter-signals.

The [product brief](../brief.md), [Saved Searches spec](../saved-searches-spec.md), [design brief](../../design/saved-searches-ux-brief.md), and [roadmap](../roadmap.json) preserve these caveats.
