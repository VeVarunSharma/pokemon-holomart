# Synthetic evidence index

> **Provenance label: SYNTHETIC / DEMO-ONLY.** Every record in this directory was authored for the Signal Desk demo. It is not derived from real interviews, tickets, telemetry, vendors, or customers and must not be presented as factual market research.

The evidence intentionally disagrees in places. It supports discussion, not automatic prioritization.

| Evidence | IDs | Provenance and limitation |
| --- | --- | --- |
| [Customer and support signals](customer-support-signals.md) | `CI-*`, `SS-*` | Fictional composite notes and tickets; tiny, non-representative sample |
| [Usage and analytics](usage-analytics.json) | `AN-*` | Hand-authored aggregate event counts for an invented 14-day preview cohort |
| [Market and competitive notes](market-notes.md) | `MK-*` | Desk-research-style fictional observations; no live claims or vendor ranking |

## Reading guidance

- A quote is a prompt for a question, not proof.
- Counts are directional examples and do not establish causality.
- Competitive patterns describe possible expectations, not parity requirements.
- Roadmap initiatives cite IDs and counts so a human can inspect how much support exists.

The [product brief](../brief.md), [Saved Views spec](../saved-views-spec.md), [design brief](../../design/saved-views-ux-brief.md), and [roadmap](../roadmap.json) should preserve these caveats.
